# Prompt — Plan an Engineering Migration Milestone

Create an implementation-ready engineering migration package for:

```text
{milestone}
```

Classify changes as required, conditional, deprecated, manual-review, or no-op.

When applicable, plan:

- `.review/` and canonical review commands;
- thin Bash/PowerShell launchers over shared .NET logic;
- explicit tested-platform support;
- resumable validation suites;
- atomic fingerprinted receipts;
- machine-readable validation plans;
- fast aggregate verification.

Generate an execution prompt in chat. Do not require the implementation agent to read the external guide repository.
